# 🌻 新手指南 —— 不会写代码也能用好、也能帮上忙

> 这篇是写给"完全没接触过 AI 编程工具"的你。不需要任何编程知识，只要会复制粘贴、会打字，就能走完全程。

English version: [start-here.md](start-here.md) · 贡献进阶版见 [CONTRIBUTING.md](../CONTRIBUTING.md)

## 一、design-garden 是什么？（说人话版）

想象你认识一位**什么都懂一点的设计老师傅**：海报、图标、logo、店面布置、PPT、甚至"这个颜色配那个颜色丑不丑"都能问。

`design-garden` 就是把这位老师傅的"工作经验手册"装进你的 AI 助手里。它有三层：

1. **手册本身**（装好就有）—— 各种设计的手艺和避坑清单
2. **越用越聪明**（自动发生）—— 每次帮你做完设计，它都会在手册里记一笔"这次什么方法管用"，下次做得更好
3. **大家帮忙喂它**（就是我们）—— 全世界用的人把好经验捐回来，它对所有人都变好

**你不需要懂"它怎么做到的"，就像你不需要懂汽车发动机也能开车。**

## 二、装上它（两分钟）

前提：你电脑上有一个能装"技能包"的 AI 助手（比如 ZCode 或 Claude Code）。如果你连这个都没有，先去装一个，或者直接跳到第四节——不装也能帮忙。

**第一步**：打开终端（Windows 按 `Win + R`，输入 `powershell` 回车；Mac 打开"终端"）。

**第二步**：粘贴这一行，回车：

```bash
git clone https://github.com/iifzx/design-garden.git ~/.agents/skills/design-garden
```

看到一串"Cloning into..."就成功了。就这么简单——它现在已经是你的 AI 助手的一部分了。

**第三步**（每次使用）：打开你的 AI 助手，直接说人话就行，比如：

> "帮我给小区的流浪猫募捐做一张海报"

> "我水果店要一张朋友圈促销图，卖荔枝的"

> "这张图看着怪怪的，你帮我看看问题在哪"（把图发给它）

> "帮我给女儿生日派对做个邀请函网页"

如果第一次没触发（它没表现出"设计师"的样子），就直接说："用 design-garden 帮我……"。

## 三、用完之后

- **它会自己记笔记**，你不用做任何事。用得越多，它越懂你常做的这类设计。
- **不满意就直接说**："配色重新来"、"太花哨了，庄重点"——它听得懂，还会把你的偏好记下来。
- **想看它的思考过程？** 直接问"你按什么风格做的？为什么？"——它会给你讲清楚（这也是学习设计的好办法）。

## 四、五分钟帮上忙（不用写一行代码）

科技应该服务大众——**这个项目靠普通用户的支持活着**。从上往下，越往下越进阶：

| 门槛 | 你能做的 | 花多久 |
|---|---|---|
| ⭐ | 给仓库点一个 Star——让更多人刷到它 | 10 秒 |
| 🗳️ | 打开 [Discussions](https://github.com/iifzx/design-garden/discussions) 里最新的**投票贴**：两张图哪张更好看？回个 **1** 或 **2** 就行 | 30 秒 |
| 🌻 | 提交一份[**小白报告**](https://github.com/iifzx/design-garden/issues/new?template=beginner_bloom.yml)：回答 3 个问题——你让它做了什么？结果怎样？哪里惊喜/哪里不满意？ | 2 分钟 |
| 📋 | 把你**真实的设计需求**发成 issue（"我需要一张寻猫启事"）——好的真实需求会变成项目的测试题，让 skill 变得更懂生活 | 3 分钟 |
| 🌱 | 用顺手了？回到 [CONTRIBUTING.md](../CONTRIBUTING.md)，那里有正经的贡献路线：分享经验、写风格配方、做评审 | 一杯茶的时间 |

你的"小白报告"真的有用：每一条都会被整理进知识库——**你觉得"哪里不对劲"的直觉，正是机器最缺的东西。**

## 五、小词典（就 4 个词）

- **AI 助手 / agent**：运行在你电脑上、能帮你干活的 AI 程序
- **skill / 技能包**：给 AI 助手装的一本"专业手册"，design-garden 就是一本设计手册
- **盲投票**：不告诉你哪张是谁做的，纯凭感觉选——这样投票才公平
- **PR / 贡献**：把自己的一份小内容捐进这个公共手册

## 常见小问题

- **粘贴命令报错"路径不存在"？** 先运行 `mkdir -p ~/.agents/skills` 再重试。
- **没装 git？** Windows 装 [Git for Windows](https://git-scm.com/download/win)，Mac 装 Xcode 命令行工具即可。
- **它做的图不是我想要的风格？** 直接用一句话描述你想要的感觉（"像宜家说明书那种简单清爽"）——说得越像人话，它做得越准。
- **想删掉它？** 删掉那个文件夹就行，不留任何痕迹。
