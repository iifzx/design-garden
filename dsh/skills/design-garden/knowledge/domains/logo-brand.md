# Logo & brand identity

## Choose the logo type first
| Type | Form | Fits |
|---|---|---|
| Wordmark | Styled name | Law, finance, agencies — the name is the asset |
| Lettermark | Initials | Long or technical names |
| Pictorial | Literal object | Food, consumer goods |
| Abstract | Geometric symbol | Tech startups building an ownable asset |
| Mascot | Character | Food, sports, community |
| Emblem | Text inside symbol | Craft, coffee, institutions, badges |
| Combination | Mark + word | Safe default; splits apart at small sizes |

Industry pull: tech startup → abstract/combination; law & finance →
wordmark/emblem; food → pictorial/mascot; agency → wordmark/abstract.
Justify the choice against the brief, not habit.

## Scalability — non-negotiable
- Recognizable at 16×16 favicon size.
- Works in single color, in pure black, and in pure white.
- No details that vanish when small: gradients, hairlines, tiny text
  inside the mark.
- Passes silhouette test (solid fill still reads) and blur test (softened,
  still reads).

## Distinctiveness
- Swap test: if a competitor could use the logo unchanged, redesign it.
- Skip generic swooshes, globes, and shields unless the business is
  literally about those.
- Wall test: place it beside 5 competitor logos — it must not blend into
  the row.

## Construction
- Build on a grid with geometric anchors (circles, 45°/60° angles) so the
  mark can be re-derived, not traced.
- Compose from basic shapes; add complexity only when it carries meaning.
- Share the stroke-width and corner-radius family with the product's icon
  system — logo and icons should read as relatives.
- Optically center. Mathematical centering looks off; nudge until the eye
  agrees.

## Logo system
- 4 variants: full-horizontal, stacked, icon-only, wordmark.
- 4 colorways: full-color, reversed (on dark), mono-dark, mono-light.
- Clear space = the mark's height on every side.
- Minimum sizes: 120px wide for the full logo, 24px for the icon.
- Ten don'ts: stretch, rotate, shadow, gradient-fill, outline, crop, busy
  backgrounds, arbitrary recolors, rebuilding the wordmark in another
  typeface, mixing variants in one placement.

## Color
| Color | Signals | Watch out |
|---|---|---|
| Blue | Trust, finance, tech | Food — suppresses appetite |
| Red | Food, energy, urgency | Healthcare defaults |
| Green | Eco, health, growth | Reads cheap on premium goods |
| Yellow | Optimism, quick service | Loses gravitas in finance |
| Purple | Luxury, creative | Tech/crypto cliché risk |
| Black | Premium, minimal | Playful kids brands |

- Palette structure: 1–2 primary, 2–3 secondary, 3–5 neutrals, 4 semantic
  (success / warning / error / info).
- Usage ratio: 60–70% primary, 20–30% secondary, 5–10% accent.
- Text never pure #000 — near-black like #1A1A1A reads richer.
- ≤2–3 colors per component; ≤20% of any surface off-palette.

## Brand voice
- Voice is constant; tone adapts per channel and audience.
- Define 3–5 traits as "X, not Y" pairs: "witty, not jokey", "plain, not
  dumbed-down".
- Competitor test: if a competitor would plausibly say the sentence,
  rewrite it.

## Messaging ladder
mission → vision → value proposition → positioning → key messages →
proof points.
- Positioning fill-in: "For [target] who [need], [Brand] is a [category]
  that [benefit]. Unlike [competitors], we [differentiator]."
- Test each message on five axes: clear, differentiated, credible,
  compelling, consistent.
- Proof points are facts that exist. Never invent statistics, clients, or
  awards.

## Tokens and assets
- The guidelines doc is the source of truth; sync it into design tokens
  so product UI cannot drift.
- Asset naming: `{type}_{campaign}_{description}_{YYYYMMDD}_{variant}.{ext}`.
- Archive superseded assets; never delete — rebrands get audited and old
  marks come back.

## Critique checklist
- [ ] Logo type chosen from the 7-type matrix with stated industry fit
- [ ] Recognizable at 16×16 favicon
- [ ] Works single-color and in pure black and white
- [ ] Passes silhouette and blur tests
- [ ] Passes the swap test — a competitor could not reuse it
- [ ] Wall test beside 5 competitors shows distinctiveness
- [ ] Grid-constructed from basic shapes with geometric anchors
- [ ] Stroke/radius family shared with the icon system
- [ ] Mark optically centered
- [ ] 4 variants × 4 colorways delivered
- [ ] Clear space = mark height; min sizes 120px full / 24px icon documented
- [ ] None of the 10 don'ts appear in mockups
- [ ] Palette structured 1–2 primary / 2–3 secondary / 3–5 neutrals / 4 semantic
- [ ] Usage ratio 60–70 / 20–30 / 5–10 held; ≤20% off-palette
- [ ] No pure #000 text; ≤2–3 colors per component
- [ ] 3–5 voice traits written as "X, not Y" pairs
- [ ] Positioning statement completes the fill-in template
- [ ] Assets named per convention and archived, not deleted
