# Retro-Futurism

**Identity:** 60s space-age optimism — orbital rings, starbursts, orange and teal on cream, chrome-rounded frames that promised tomorrow.
**Temperature:** bold
**Best for:** science and education brands, product launches framed as "the future", title sequences, museum exhibits.
**Avoid when:** the subject is dark, ironic, or dystopian — this style is sincere optimism.

## Palette
- Cream `#F3EAD8` — ground; ~60%
- Rocket orange `#F0632F` — primary pop; ~18%
- Teal `#2A8F9B` — counterweight; ~15%
- Ink navy `#232D3F` — outlines, type; ~5%
- Silver `#B9BEC7` — chrome details; ~2%
- Halftone dots shade forms; no airbrush gradients

## Type
- Display: **Jost** (open license, Futura-class) 500–600 caps, tracking +8%
- Annotations: **Space Mono** (open license) 400 — technical-diagram voice
- Scale 1.414: 16 / 23 / 32 / 45 / 64
- Display always uppercase; annotations sentence case at 13–14px
- Numerals oversized where possible — countdowns, orbit numbers

## Layout grammar
- Centered hero with orbital rings circling it
- Starburst or atomic fan radiating behind the focal object
- Rounded-rectangle chrome frames and badges hold titles
- Horizon curvature at the composition's base
- Mono annotations with leader lines, like a technical schematic
- Symmetry welcome but not mandatory; orbits set the rhythm

## Signature moves
- Orbital rings with node dots — the atom motif
- Starburst rays behind the hero element
- Halftone dot shading on forms
- Chrome rounded-rect badges with engraved-looking caps
- Mono leader-line callouts ("CAPSULE — 04")

## Motion & interaction
- Orbital rotations: 12–20s linear loops, seamless
- Entrances travel along arc paths, 300–500ms
- Starbursts rotate slowly behind static heroes
- Mechanical smooth easing only — no bounce

## Do / Don't
- Do: keep the palette to orange+teal+cream with silver trim
- Do: use annotations as texture — they add scientism
- Do: let one orbital system organize the whole composition
- Don't: drift into 80s synthwave — neon grids, purple lasers, and chrome-sunset text belong to another style
- Don't: add dystopian grit, noise, or glitch
- Don't: render gradients as airbrush; halftone keeps it period-correct
- Don't: exceed one orbital system per composition; nested orbits tangle
- AI failure mode: synthwave bleed (purple/cyan neon) — if the palette trends purple, restart from cream+orange+teal and re-add the orbit
