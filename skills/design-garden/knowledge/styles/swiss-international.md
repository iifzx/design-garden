# Swiss International

**Identity:** Mathematical grid, grotesk type flush-left, whitespace doing the persuasive work — order you feel before you read a word.
**Temperature:** neutral
**Best for:** design and engineering tooling, architecture and culture brands, data-heavy decks, systems docs, anything arguing for precision.
**Avoid when:** audience needs warmth or play — kids, hospitality, gifting, emotional storytelling.

## Palette
- Paper `#F7F6F2` — warm off-white ground; dominates ~65%
- Ink `#141414` — warm near-black for type and rules; ~25%
- Signal red `#E32919` — the classic accent; ration to ≤2%, one use per view
- Steel gray `#8B8B85` — captions, metadata, inactive states; ~8%
- Modern muted variant: replace red with ochre `#C77B2E` or ink blue `#2E4A8F`
- Hard ceiling of 4 values — a fifth color breaks the objectivity

## Type
- One grotesk throughout: Neue Haas Grotesk / Helvetica Now; open license: **Inter** or **Archivo**
- Weights 400 / 500 / 700 only — no light, no black
- Scale 1.25: 16 / 20 / 25 / 31 / 39 / 49
- Display tracking -1% to -2%; body normal; never letterspace lowercase grotesks
- Numerals: tabular in tables, oversized as section markers

## Layout grammar
- 12-column grid; gutter width equals outer margin width; every element obeys
- 8px baseline grid — all vertical rhythm lands on it
- Margins generous: ≥15% of canvas width on posters, ≥96px on web
- Asymmetry via column spans (5+7, 4+8), never via decoration
- Leave entire quadrants empty; whitespace is structure, not leftover
- Photography objective: flat light, straight-on angle, crop aligned to columns

## Signature moves
- 1px ink hairlines structuring content like a technical drawing
- Oversized index numerals (49–120px) marking sections
- Exactly one red element per view: a rule, a dot, a single word
- Photo crops that hard-align to grid edges, mid-column when it hurts
- Fixed text measure 45–75 characters, flush-left ragged-right everywhere

## Motion & interaction
- 150–250ms ease-out fades and 8px slides; nothing springy, nothing scaling
- Hover: color shift to accent or underline reveal; no shadow, no lift
- Page changes cut like slide-projector clicks — no morphing
- Chart and diagram animations draw straight, ≤400ms, then stop

## Do / Don't
- Do: establish hierarchy with whitespace first, type size second, color last
- Do: align every edge — including photos — to the grid, even when it crops awkwardly
- Do: treat the accent like a highlighter: rare, purposeful, one per view
- Don't: center text; a centered block in Swiss work is a typo, not a choice
- Don't: add shadows, gradients, or corner radii — they read as contamination
- Don't: "warm it up" with serifs, textures, or illustration unless briefed
- Don't: exceed the 4-value palette to differentiate sections; use rules and scale instead
- AI failure mode: decorative creep (blobs, textures, drop shadows) and politely centered "balanced" layouts — if it looks friendly, it failed the brief
