# Eval task: logo-brand-02
- domain: logo-brand
- deliverable: Logo system (4 variants × 4 colorways) + color rationale + voice
  traits + messaging ladder with honest placeholders

## Brief

Meridian Labs does blockchain security work — smart-contract audits and
key management for fintech clients. Buyers are CTOs and compliance
officers who are professionally allergic to crypto-bro aesthetics. Hard
constraints: no neon gradients, no glowing hexagons, no green matrix
motifs, no circuit-board clichés. The mark must read at 16×16 favicon,
emboss onto report covers, and hold up in a wall test beside five
security competitors. Deliver: logo type justified against the seven-type
matrix (combination or wordmark likely), four variants across four
colorways, a palette with color-psychology rationale for the industry,
voice as 3-5 "X, not Y" traits, a positioning statement using the fill-in
template, and a messaging ladder from mission down to proof points.
Proof points must be written as explicit placeholders — do not invent
statistics, clients, or certifications.

## Deliberate traps

- Hexagon-plus-circuit-lines mark with a neon gradient — the crypto
  default this brief bans
- Thin-stroked mark that fails at 16px and in single-color embossing
- Invented audit counts, client names, or certifications as proof points
- Voice any security vendor could have written — fails the competitor
  test
- Default crypto purple-blue palette picked without psychology rationale

## What strong output looks like

- Swap and wall tests passed; works mono, at 16px, and on report covers
- Type choice argued from the 7-type matrix, not habit
- Palette tied to trust psychology with industry avoid-notes applied
- Complete positioning fill-in plus mission-to-proof-points ladder with
  honest placeholders
- All ten logo don'ts avoided in every mockup
