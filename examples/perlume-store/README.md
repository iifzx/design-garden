## 规格

- 商店图：2048×2732，3:4，JPEG q95（`subsampling=0`、`optimize`），单张 0.67–1.17 MB。
- 文案层：标题 CJK 132px Bold，字距 14；副标 52px Regular，字距 3；封面字标 mark 高 320、篆体名 328；功能图底部署款高 88、居中。
- 内容区：真机截图原图 2979×2016（RGBA，四角透明），等比缩至 1900×1286，顶边 y=940；只叠两层投影 `(0,54,130,0.26)` 与 `(0,16,42,0.18)`，不裁屏、不重描外壳。
- 安全区：标题墨迹在 y=250 / y=434，副标 y=626，截图从 y=940 起 —— 与商店详情页顶部的裁切保持距离。

## 生成方式

- 底片是只含风景的摄影图（无烧入文字），逐页按主体位置裁切、调色。
- 字标与全部中文由 Pillow 在代码里合成：矢量字标先栅格化，再按 alpha 定位；正文用 Noto Sans SC 变量字体的字重实例。
- 真机截图来自实际设备，未做任何 UI 重绘或"美化"。

## 为什么这么排

1. **内容区必须是原图。** 商店图的截图是产品证据，重绘外壳会把"演示"变成"渲染"。
2. **中文不能交给生成模型。** 生成图里的汉字错一笔就废，标题这类大字号尤其明显。
3. **缩略图优先。** 商店列表与搜索结果里图只有两百来像素宽，识别必须由大标题承担，细节只负责第二眼。
