# Sources — what the garden was planted from

design-garden v0.1 was seeded by distilling knowledge from existing design skills and craft references. Everything in `knowledge/` is **re-expressed in fresh wording** — we carry ideas, not sentences — and each knowledge file names its sources in its `source:` frontmatter field. If you are one of these authors and want attribution changed or content removed, open an issue and we'll fix it promptly.

## Fonts

v0.1 does not bundle fonts. Style recipes name open-license (OFL) families — respect each family's license when you install them locally.
